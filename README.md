# Abdurrahman Khan — Portfolio

A light, responsive personal portfolio built with React.js and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The build is in `dist/` and can be hosted by any static hosting provider.

## Content

Edit `src/main.jsx` to update content and `src/styles.css` to adjust the design. The original supplied resume is at `public/Abdurrahman_Khan_Resume.pdf`.

The contact form validates required fields and opens the visitor's email application using a mailto link. It does not send email or save submissions. No backend or credentials are required.
